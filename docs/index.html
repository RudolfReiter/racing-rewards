The research behind the demonstration

The paper combines discrete obstacle and reward decisions with continuous vehicle motion planning. The implementation below preserves that structure with the simplifications stated here.

01

Choose the corridor

A mixed-integer linear program selects a passing side for each obstacle and whether to enter each reward gate. Absolute lateral deviation and slope compete with reward value.

min deviation + slope − rewards
02

Refine the path

A spline optimizer keeps the selected corridor and progressively tightens its bounds. The final solve uses no corridor relaxation.

relaxation: 1.5 → 0.4 → 0 m
03

Construct the motion

Curvature limits the speed. Forward and backward passes enforce longitudinal acceleration and braking limits along the path.

v² |κ| ≤ 5 m/s²
What this recreation does and does not recover This is a simplified recreation, not the original Roborace implementation. It uses synthetic tracks, short reward gates, a spline path optimizer, and a curvature-based speed profile. It does not reproduce the paper’s nonlinear multiple-shooting vehicle OCP, slack-penalty continuation, embedded timings, or Bedford experiments. The animation shows a computed plan, not measured tracking performance. See REPRODUCTION.md in the source archive for the equation-to-code mapping and evaluation protocol.

All nine runs use the same three synthetic 240 m track scenes. Clearance is sampled in Frenet coordinates against inflated rectangular obstacles, including the vehicle footprint allowance. It is not an exact Euclidean body distance.

A higher reward weight can increase travel time. The optimizer’s surrogate objective is not lap time, and these numbers are not a reproduction of the original paper’s results.

Run the planner and inspect the results

A self-contained Python package, deterministic examples, numerical checks, and a static website. No external assets or account are required to view the demonstration. 

python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m racing_rewards.experiment
python scripts/plot_results.py
python -m pytest -q
python -m http.server 8000 --directory docs

Run these commands from the repository root after cloning or extracting the source archive. Open localhost:8000 to view the page.

Python 3.9–3.12 is recommended for the pinned reproduction environment. The exported data ships with the repository, so viewing the page does not require running the optimizer. Solve times depend on the machine and solver versions.
